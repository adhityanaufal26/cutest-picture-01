# cutest-picture-01

An irresistibly cute picture for the make.fun cutest-picture-01 bounty: a tiny fluffy orange kitten with huge round amber eyes and a tiny pink nose, sitting in a sunlit meadow dotted with tiny white and yellow wildflowers, in soft golden morning light.

## Files

- `entry.png` — the cute picture (1024x683, PNG, 940,612 bytes).
- `main.py` — the program: copies entry.png to `/output/entry.png`.
- `LICENSE` — MIT.
- `.makefun/owner.json` — claim file naming the entry wallet.
